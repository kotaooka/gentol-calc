JIS B 0405 / B 0419 / B 0403 / DIN 16901 / ISO 3302-1 / 板厚

公差の指示がない寸法に当てはまる普通寸法公差（JIS B 0405）と普通幾何公差（JIS B 0419）を表示します。行を選ぶと、その寸法の詳細と早見表の該当欄を示します。

早見表

選んだ寸法が入る範囲の列と、選んでいる等級の行を色で示します。単位は mm（角度を除く）。「—」は規格に値がない欄です。

JIS B 0405:1991（ISO 2768-1）、JIS B 0419:1991（ISO 2768-2）。表の値は規格の内容から起こしたもので、規格票との照合はまだです。

DIN 16901 の一般公差（公差の指示がない寸法に当てはめる ± の値）を表示します。材料から公差グループを選び、寸法が型の可動部をまたぐかどうかで A と B を切り替えます。

材料と寸法

寸法の種類

B は 1 つの型部品の中で決まる寸法。A は肉厚・底厚、スライドや突き出しなど型の可動部で決まる寸法で、B より 0.10 mm 広くなります。
