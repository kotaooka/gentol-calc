# 普通公差計算機（gentol-calc）

寸法を入れると、公差の指示がない寸法に当てはまる普通公差と、金属材料の板厚の許容差を表示する Web ツールです。機械加工・樹脂成形品・鋳造品・ゴム製品・板厚をタブで切り替え、寸法をまとめて入れると ± の値と上下限を一覧にし、早見表の該当欄を色で示します。

**https://kotaooka.github.io/gentol-calc/**

インストールは不要で、ブラウザで開くだけで使えます。

- **データは外に出ません**。計算はすべてブラウザの中で行い、どこにも送信しません
- 画面の字体（BIZ UDPゴシック・IBM Plex Mono）は Google Fonts から読み込むため、開いたときに Google のサーバーへ接続します。入力した値は送りません
- 入力した値と選んだ条件はこの端末のブラウザに自動で保存し、次に開いたときに続きから使えます
- 一度開けば**オフラインでも動きます**。スマートフォンや PC にアプリとして追加することもできます

## できること

| タブ | 規格 | 選ぶもの |
|---|---|---|
| 機械加工 | JIS B 0405（ISO 2768-1）、JIS B 0419（ISO 2768-2） | 公差等級 f / m / c / v と H / K / L |
| 樹脂成形品 | DIN 16901 一般公差 | 材料（公差グループ 130〜160）、寸法の種類 A / B |
| 鋳造品 | JIS B 0403（ISO 8062） | 鋳造公差等級 CT1〜CT16、肉厚かどうか |
| ゴム製品 | ISO 3302-1 | 成形品 M1〜M4（F / C）、押出品の断面 E1〜E3、切断長さ L1〜L3 |
| 板厚・肉厚 | JIS G 3141、JIS G 4305、JIS H 4000、JIS H 4100 | 規格ごとの表、幅、合金の区分、外接円の直径など |

- 寸法は 1 行に 1 つ入れます。`φ8`、`2-φ5.5`、`t1.6` のような書き方も読めます
- 機械加工のタブでは、`C0.5`・`R3` を面取り・かどの丸みの表で、`30°/25`（角度 / 短い辺の長さ）を角度の表で引きます。行を選ぶと、その長さで決まる普通幾何公差（真直度・平面度・直角度・対称度・円周振れ）も並べます
- 規格の範囲の外の寸法や、表に値がない組合せは、理由を添えて「個々に指示」などと表示します
- 結果は「結果をコピー（Excel 用）」で、Excel にそのまま貼り付けられる形でコピーできます

## 表の値について（必ず読んでください）

表の値は、規格票ではなく**公開されている資料（メーカーの技術資料、規格の抜粋、改正原案など）から起こしたもの**です。資料ごとの照合の状況を画面の各表の下に書き、照合が足りない値には一覧で **△** を付けています。図面の指示や受入判定に使う前に、△ の付いた値は規格票で確かめてください。

- **DIN 16901** は廃止された規格です（DIN は後継に DIN 16742 を挙げています）。図面に今も DIN 16901 と書かれている部品のために載せています。直接記入する公差（110〜160 の全幅）は、資料の読み取りの誤りが多いため載せていません
- **JIS H 4000** は 1999 年版の値です。現行の 2022 年版とは照合できていません。熱間圧延材（その2）は 2017 年の追補で表が差し替わり、新しい値が見つからないため載せていません
- **JIS G 4305** の記号 ST の表は、値を確かめられる資料が見つからないため載せていません
- **VDI 2005**（ゴム部品）は、許容差の表を確かめられる資料が見つからないため載せていません

資料の一覧と、表ごとの照合の詳細は [docs/sources.md](docs/sources.md) にあります。規格票で値を確かめて違いがあれば、Issue で知らせてください。

## 計算の検証

表の値は `js/tables.js` にまとめ、検査テストを付けています（push のたびに GitHub Actions で実行）。

- 各表の行と列の数、寸法範囲の並び
- 値が寸法・等級とともに広がること（鋳造公差は行と列の両方向）
- DIN 16901 のグループ間の大小、出典と突き合わせた代表値

開発者向けの情報は [DEVELOPMENT.md](DEVELOPMENT.md) にあります。
