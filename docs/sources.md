# 表の出典と照合の状況

表の値は規格票ではなく、下の公開資料から起こしました（2026-10-17 時点。JIS B 0408・B 0410 は 2026-10-27 時点）。「照合済み」は複数の独立した資料で値が一致したこと、「1 資料」は 1 つの資料だけで確かめたことを指します。どの表も規格票そのものとは照合していません。

## JIS B 0405:1991 / JIS B 0419:1991

- 値は規格の内容から起こしました。公開資料との照合はしていません
- 対称度の範囲の取り方（長い方の形体をデータムにとる）と、真円度・平行度の扱いの注記は、規格票で確かめてください
